# portfolio-person

Личное портфолио исполнителя в виде Telegram Mini App: статичные `index.html` + `portfolio.json`, без сборки,
публикация на GitHub Pages. Инструкция — `README.md`.

## Правила

- В «Мои проекты» — только собственные реальные проекты и проверенные цифры. Проекты команды Anadept сюда не
  добавляем (они в портфолио компании: репозиторий `anadeptby-debug/botsearchorder`, `lead_radar/portfolio.py`,
  и сайт anadept.tech).
- «Решения под задачу» — предложения по востребованным темам, без утверждений о прошлых проектах.
- Демо — только работающие, с пометкой `kind: "demo"` или ссылкой `demo_url` у решения.
- Тексты на русском, без канцелярита и штампов; цвета — из темы Telegram (`--tg-theme-*`), светлая и тёмная тема.

Связанный проект: Lead Radar (`anadeptby-debug/botsearchorder`) — ищет заказы и готовит черновики откликов;
ссылки `?startapp=<id>` из этого портфолио можно вставлять в отклики «от себя».
