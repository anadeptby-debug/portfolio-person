# Личное портфолио — Telegram Mini App

Одна страница без сборки: `index.html` + `portfolio.json`. Открывается внутри Telegram (берёт цвета темы,
кнопка «Обсудить задачу» внизу экрана, кнопка «Назад») и в обычном браузере.

## Что внутри

Портфолио оформлено как переписка с ботом — это и есть демонстрация того, что вы делаете.

- **Приветствие**: имя, одна строка о вас, направления плашками (`profile.skills`).
- **Карусель «6 решений под задачу»** приходит сразу. Карточки одной высоты, у каждой своя цветная обложка
  с мини-макетом (палитры `.p-<id>` и макеты `MOCKS` — в `index.html`), категория, пометка «Демо готовлю» или
  «Есть демо». Стрелки и точки показывают, что карточки листаются.
- **Карточка решения** открывается панелью: обложка с крупным макетом, задача, чек-лист «Что входит»,
  «Кому подойдёт», цена и срок, кнопки «Все решения» и «Обсудить эту задачу» (в Telegram — встроенная кнопка).
- **Интерактивный пример** (поле `example` у решения, сейчас — у ИИ-ассистента): посетитель задаёт готовые
  вопросы вымышленной клинике и видит ответы с источником, в том числе честное «в документах этого нет —
  передам администратору». Пример подписан: ответы заготовлены.
- **Кнопки внизу**: «Решения», «Сколько стоит?», «Как работаешь», «Написать лично». «Написать» и «Обсудить»
  открывают чат с вами с заготовкой первого сообщения.
- Раздел проектов появится, когда в `cases` будут собственные реальные проекты.

Фон — бледный узор (скобки кода, шестерёнки, облачка), чтобы не мешать тексту; работает в светлой и тёмной
теме, анимация «печатает…» отключается, если в системе выключены анимации.

Все тексты — в `portfolio.json`. HTML трогать не нужно.

## Перед публикацией

В `portfolio.json` → `profile` заполните:
- `name` — имя;
- `role` — специализация одной строкой;
- `telegram` — username без @ (на него ведёт кнопка «Обсудить задачу»);
- `photo` — ссылка на фото (можно положить файл в репозиторий и указать `photo.jpg`); пусто — будут инициалы.

Проверьте тексты решений и шаги «Как работаю»: это ваши обещания заказчику.

## Публикация на GitHub Pages

1. Репозиторий → Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
2. Через минуту страница будет по адресу `https://anadeptby-debug.github.io/portfolio-person/`.

Подойдёт и любой другой HTTPS-хостинг (Cloudflare Pages и т.п.): достаточно выложить два файла.

## Подключение к боту

1. В @BotFather: `/newapp` → выберите бота → вставьте адрес страницы → придумайте короткое имя, например `portfolio`.
2. Ссылка на портфолио: `https://t.me/<бот>/portfolio`.
3. Ссылка сразу на нужную карточку: `https://t.me/<бот>/portfolio?startapp=<id>`, где `id` — из
   `portfolio.json` (`ai-assistant`, `telegram-bot`, `marketplace-parser`, `crm-integration`, `ai-1c`, `website`). Удобно вставлять в отклики.

Проверка локально: `python3 -m http.server 8000` в папке репозитория и открыть http://localhost:8000.
