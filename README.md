# Личное портфолио — Telegram Mini App

Одна страница без сборки: `index.html` + `portfolio.json`. Открывается внутри Telegram (берёт цвета темы,
кнопка «Обсудить задачу» внизу экрана, кнопка «Назад») и в обычном браузере.

## Что внутри

Портфолио оформлено как переписка с ботом — это и есть демонстрация того, что вы делаете.

- **Приветствие**: имя, одна строка о вас, направления плашками (`profile.skills`).
- **«Что я делаю»** — карусель направлений: карточки одной высоты, у каждого направления свой спокойный цвет
  обложки с примером интерфейса (палитры `.p-<id>` и макеты `MOCKS` — в `index.html`) и категория.
  Последняя карточка — «И многое другое»: веб-приложения, интеграции по API, скрипты, доработка кода, серверы.
- **Карточка направления** открывается панелью: пример интерфейса, «Что умею в этом направлении»,
  «Где пригодится», «Стек» (`stack` у направления — проверьте и поправьте под себя), кнопки «Все направления»
  и «Написать».
- **Интерактивный пример** (поле `example`, сейчас — у ИИ-ассистента): готовые вопросы вымышленной клинике и
  ответы с источником, в том числе честное «в документах этого нет — передам администратору». Подписан как пример.
- **Клавиатура бота внизу**, как в Telegram: «Что ты делаешь», «Как работаешь», «Сколько стоит?»,
  «Написать мне». «Написать» открывает чат с вами с заготовкой первого сообщения.
- Раздел проектов появится, когда в `cases` будут собственные реальные проекты.

Фон — бледный узор (скобки кода, шестерёнки, облачка), чтобы не мешать тексту; работает в светлой и тёмной
теме, анимация «печатает…» отключается, если в системе выключены анимации.

Все тексты — в `portfolio.json`. HTML трогать не нужно.

## Перед публикацией

В `portfolio.json` → `profile` заполните:
- `name` — имя;
- `role` — специализация одной строкой;
- `telegram` — username без @ (на него ведёт кнопка «Обсудить задачу»);
- `photo` — ссылка на фото (можно положить файл в репозиторий и указать `photo.jpg`); пусто — будут инициалы.

Проверьте тексты решений и шаги «Как работаю»: это ваши обещания заказчику.

## Публикация на GitHub Pages

1. Репозиторий → Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
2. Через минуту страница будет по адресу `https://anadeptby-debug.github.io/portfolio-person/`.

Подойдёт и любой другой HTTPS-хостинг (Cloudflare Pages и т.п.): достаточно выложить два файла.

## Подключение к боту

1. В @BotFather: `/newapp` → выберите бота и ответьте на вопросы:
   - **Title:** `Портфолио`
   - **Description:** `Боты, ИИ-ассистенты и автоматизация для бизнеса. Листайте направления и пишите — отвечу лично.`
   - **Photo:** `assets/botfather-cover.png` (640×360; исходник — `assets/botfather-cover.html`)
   - **GIF:** `/empty`
   - **Web App URL:** адрес страницы из раздела «Публикация»
   - **Short name:** `portfolio` (латиница, цифры и `_`, от 3 до 30 символов)
2. Ссылка на портфолио: `https://t.me/<бот>/portfolio`.
3. Ссылка сразу на нужную карточку: `https://t.me/<бот>/portfolio?startapp=<id>`, где `id` — из
   `portfolio.json` (`ai-assistant`, `telegram-bot`, `marketplace-parser`, `crm-integration`, `ai-1c`, `website`). Удобно вставлять в отклики.

Проверка локально: `python3 -m http.server 8000` в папке репозитория и открыть http://localhost:8000.

## Оформление бота

Перед открытием Mini App Telegram показывает чат с ботом, и потом бот остаётся в списке чатов клиента. Пусть он
работает как визитка.

### В @BotFather (без кода)

`/mybots` → ваш бот → **Edit Bot**:

| Поле | Что вставить |
|---|---|
| **Name** | `Имя Фамилия · разработка и ИИ` — так бот называется в списке чатов |
| **About** (до 120 символов, видно в профиле) | `Боты, ИИ-ассистенты, автоматизация, 1С и CRM, парсинг, сайты. Портфолио — кнопка «Открыть».` |
| **Description** (до 512 символов, видно в пустом чате до нажатия «Старт») | `Здравствуйте! Это моё портфолио. Делаю Telegram-ботов и Mini Apps, ИИ-ассистентов, автоматизацию, интеграции с 1С и CRM, парсинг, сайты и веб-сервисы. Нажмите «Старт» — пришлю кнопку портфолио. Задачу можно описать прямо здесь, отвечу лично.` |
| **Description Picture** | `assets/botfather-cover.png` (640×360) |
| **Botpic** | `assets/bot-avatar.png` (512×512) |
| **Commands** | `start - Открыть портфолио` и `contact - Связаться со мной` |

**Bot Settings → Menu Button** → адрес портфолио, название `Портфолио`. Слева от поля ввода появится кнопка,
которая всегда открывает портфолио.

**Bot Settings → Configure Mini App → Enable Mini App** → адрес портфолио. В профиле бота появится кнопка «Открыть»,
а ссылка `https://t.me/<бот>?startapp=<id>` откроет портфолио сразу на нужном направлении.

### Ответ на /start (папка `bot/`)

Без обработчика бот молчит на «Старт». `bot/worker.js` — маленький Cloudflare Worker (бесплатно, без сервера):
- на `/start` присылает приветствие с кнопками «Открыть портфолио» и «Написать мне лично»;
- `t.me/<бот>?start=ai-assistant` — та же кнопка, но открывает нужное направление;
- любое другое сообщение клиента пересылает вам и отвечает «Спасибо, передал, отвечу лично».

Запуск (нужен аккаунт Cloudflare и Node.js):

1. В `bot/wrangler.toml` впишите `OWNER_USERNAME` (без @) и `OWNER_NAME` (в родительном падеже: «Ивана Петрова»).
2. В папке `bot`:
   ```bash
   npx wrangler login
   npx wrangler secret put BOT_TOKEN        # токен бота от @BotFather
   npx wrangler secret put WEBHOOK_SECRET   # любая длинная случайная строка
   npx wrangler secret put OWNER_CHAT_ID    # ваш числовой id, узнать у @userinfobot
   npx wrangler deploy                      # выдаст адрес вида https://portfolio-bot.<имя>.workers.dev
   ```
3. Подключите вебхук (подставьте токен, адрес и тот же секрет):
   ```bash
   curl "https://api.telegram.org/bot<ТОКЕН>/setWebhook" \
     -d url=https://portfolio-bot.<имя>.workers.dev \
     -d secret_token=<WEBHOOK_SECRET> \
     -d allowed_updates='["message"]'
   ```
4. Напишите боту `/start` — придёт приветствие с кнопками.

Если бот уже используется для чего-то ещё (например, Lead Radar), заведите для портфолио отдельного бота: у бота
может быть только один вебхук.
